# Security Policy

## Supported versions

RepoDoctor is currently maintained on the `main` branch. Security fixes are applied to the latest deployed version.

## Reporting a vulnerability

Please do not publish suspected vulnerabilities in a public issue.

Instead, use GitHub's private security reporting feature for this repository when available. Include:

- a concise description of the issue;
- steps to reproduce it;
- the affected route, feature, or file;
- the potential security impact;
- any suggested mitigation.

Please avoid including secrets, access tokens, private repository data, or other sensitive information in reports.

## Scope

RepoDoctor analyzes public GitHub repositories through GitHub's public API. Reports involving API handling, unsafe rendering, dependency vulnerabilities, injection risks, or unintended exposure of repository data are considered in scope.

Security reports will be reviewed as soon as practical. Confirmed issues will be prioritized according to severity and impact.
